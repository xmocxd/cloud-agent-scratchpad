# MD Documentation

This folder contains guides for contributing documentation to this repository using Markdown.

Whether you have never used Git before or are comfortable with the command line, there is a workflow here for you.

## Recommended Path

For most contributors, the recommended workflow is:

1. Install [Obsidian](https://obsidian.md) and two community plugins (Obsidian Git + obsidian-github-tools)
2. Open this repository folder as an Obsidian vault
3. Create a new branch, write your content, commit, and open a Pull Request — all from inside Obsidian

See [onboarding-guide.md](onboarding-guide.md) for the full walkthrough.
