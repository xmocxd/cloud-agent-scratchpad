# Audicode: Astro (audio-first)

Teaching scripts for **Astro.js** designed to be understood with eyes closed—headphones, podcasts, or YouTube in the background. You do not need to see code on screen to follow along.

**Source of truth:** [official Astro documentation](https://docs.astro.build/). Content is **not** based on other projects in this repository.

See [PLAN.md](./PLAN.md) for the full series plan and pedagogy.

## How to use these scripts

1. Open an episode folder (e.g. [`ep01-foundations/`](./ep01-foundations/)).
2. Read [`SCRIPT.md`](./ep01-foundations/SCRIPT.md) aloud, or record it.
3. Treat `[PAUSE]` as a breath / beat change.
4. Treat `[RECAP]` and `[REVIEW: …]` as intentional retention beats—do not skip them when recording.
5. Optionally keep [`CHEATSHEET.md`](./ep01-foundations/CHEATSHEET.md) nearby *after* listening for names and doc links. The audio must stand alone without it.

## Listening tips (for your audience)

- You can listen while walking, commuting, or working with the screen off.
- Pause after each major section recap if you want to jot one sentence in your own words.
- Replay `[REVIEW]` beats deliberately; they are spaced repetition, not filler.
- When an API name is spoken, picture its *job*, not a file of code.
